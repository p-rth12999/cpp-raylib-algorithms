# C++ Raylib Graphics Algorithms

A collection of classic Computer Graphics algorithms implemented from scratch in C++ using the **raylib** graphics library.

This repository serves as both a reusable raylib project template and a growing collection of graphics algorithms. The objective is to understand the mathematics and implementation behind each algorithm by manually computing the required pixels and rendering them using `DrawPixel()`, rather than relying on raylib's built-in drawing functions.

## Algorithms Implemented

- ✅ DDA Line Algorithm

## Technologies

- C++
- raylib 6.0
- MinGW-w64
- Visual Studio Code

## Goal

The goal of this repository is to build a reusable C++ graphics library while gaining a deep understanding of fundamental Computer Graphics algorithms through implementation from scratch.
